# Historical paired-data source qualification

This round establishes an accessible historical source and its limitations; it
does not evaluate a trading strategy. The old July availability plan lists
futures bookTicker dates ending in March 2024, while the retained native marked
funding batch covers September 5–October 6, 2026. Candles and trades cannot fill
that missing paired executable-quote evidence. The new source offers a concrete
way to investigate it without installing another collector or expanding training
on unsuitable labels.

## Evidence and result

The [source receipt](source-result.json) binds the frozen contracts, retained
native results, journals and controller bytes. Full source bodies stay in ignored
local storage. Search was one fixed two-query discovery call; snippets did not
substitute for page reading. The existing isolated Crawl4AI provider was reused
without installation, external LLMs, personal profiles or provider changes.

The first overview navigation returned native HTTP 307 and a substantive final
HTTP-200 document. Its exact-URL contract failed and its second navigation was
not run. The original contract and failure remain unchanged. A separately frozen
zero-network review allowed documentation planning from those retained bytes.
Three different technical documents subsequently passed their own predeclared
gates: [CSV types](https://docs.tardis.dev/downloadable-csv-files/data-types),
[CSV API](https://docs.tardis.dev/downloadable-csv-files/api), and
[raw HTTP API](https://docs.tardis.dev/api/http-api-reference). No overview alias
or forbidden second page was requested.

The documentation distinguishes collector arrival time from native exchange
time. Normalized timestamps can fall back to arrival time. Reconstructed CSV
quotes/depth are transformed evidence, and CSV omits disconnect markers. Raw
feeds retain exchange-native messages and disconnects. First-of-month public
access is documented without credentials; that access policy is a data-acquisition
fact, not an expiring income strategy or a runtime trading rule.

Anonymous native metadata GETs list all three supported spot/perpetual symbols
and bookTicker coverage spanning October 1. This is the sole first-of-month day
within the previously captured marked-funding window, selected by calendar and
source access before quote values. Metadata alone did not qualify file existence.

The [fixed one-minute format probe](native-minute-contract.json) then retrieved
third-party-collected exchange-native BBO records for October 1, 00:00–00:01 UTC:

| Instrument | Spot messages | Perpetual messages |
| --- | ---: | ---: |
| BTCUSDT | 9,119 | 35,658 |
| ETHUSDT | 3,905 | 22,507 |
| SOLUSDT | 2,355 | 8,277 |

All 81,821 messages passed the frozen framing/field gate. The compressed payloads
total 1,208,323 bytes; decoded payloads total 18,149,575 bytes. No disconnect marker
or collector-clock regression was observed inside this minute. That does not
prove continuous coverage, current executable capacity, owned fills or an absence
of missing messages. Local timestamps were preserved as exact nanoseconds.

Every spot message lacks native `E`/`T` clock fields; every perpetual message has
them. Spot native book age therefore remains unqualified. Substituting collector
arrival time would fabricate native freshness. No price, spread, funding return
or opportunity ranking was computed, and no model was trained.

## Polymarket route

The documented anonymous venue catalog returned 71 venues and exactly one
`polymarket` entry. Its separately frozen compact summary declares recording
since May 25, 2026 and exports through November 9. Declared channels include
books, price changes, best bids/asks, trades, market creation and resolution.
This is vendor capability metadata, not verified token-level historical data.

Important filter limits are explicit: a matching item may return a multi-token
message, and some market-level channels are not narrowed by symbol filters.
Any future capture must gate every token's scope and bound both total bytes and
messages rather than assuming the requested filter isolates one market. No
Polymarket token list, quote dataset, protected partial payload, account or order
was accessed in this round.

## What this changes

The next funding-data question can test native raw depth, sequence continuity
and generated initial snapshots under a distinct frozen source-only contract.
The vendor says snapshots are emitted on subscription; a fixed minute is not
guaranteed to contain one. Require an actual initial snapshot and exact native
update rules before reconstructing any book; stop on absence rather than extend
the window until success. Preserve native and arrival clocks separately.

For Polymarket, bind the exact outcome token, condition, payout and resolution
rules before a separately bounded data request. Historical prices alone cannot
establish equivalent settlements or realizable arbitrage. Neither route permits
replaying a consumed financial screen, choosing a better-looking date, treating
these samples as independent validation, or promoting aggregate L2 to owned fills.

Full-day coverage, usable chronological evaluation roles, both legs' native
costs/cash, financing, equal initial wealth and continuous margin solvency remain
open. All training, economic and edge-admission flags remain false. Financial
counts remain **203 observations / 65 hypotheses / 37 scoped mechanisms /
0 qualified stable edges**; source probes add no independent market observation.

## Errors and resource control

A private controller initially failed its local import before any access marker
or network request. The corrected project-root entry passed import, owned-job
and durable-write preflight; that failure is retained. Future source guidance
now requires those checks and an explicit redirect policy before freezing.
The raw-API controller's terminal text says "both" because of a reused message;
the actual contract, intent and completion prove exactly one page, not two.

Only bounded session-owned processes were used. One-use controllers were retained
as inert text after completion; raw bytes and journals remain. No recurring task,
provider installation, account credential, order, funds operation, GPU benchmark,
full test suite or GitHub push was needed. Historical numerical results and all
protected capture boundaries are unchanged.
