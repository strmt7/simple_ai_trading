## Principal problems and inefficiencies

### 1. Economic qualification is the primary product blocker

No persistent, currently qualified after-all-cost edge has been established.
The latest joint-score calculation proves unit proxy cost for a conditional
unit floor across 156 retained outcomes; its residual nine-point-margin claim
has no assigned expected value. The carry studies preserve negative scoped
results and unresolved financing/capital requirements. Binance Auto Order
Routing documents a conditional cost mechanism; API support, exact eligibility
and matched executable savings remain unproved.

Repeating those populations, adding models to invalid targets or enlarging a
dataset cannot resolve those particular gaps. The next research unit must change
a financial decision through eligible evidence, a sound cash/payoff derivation,
an independently evaluated probability or executable cost/capacity information.
Negative gross-floor evidence does not settle every expected-value question.

### 2. Component progress has outpaced complete operating workflows

Inspection, collection, application, migration, rearm and independent supervision
are still separate scopes. In particular, the current `recover-close` parser
offers `inspect` and `apply`; authenticated bounded collection is programmatic.
A user cannot yet complete the intended pending-order collection workflow through
that command. The application still needs a complete supervised vertical slice
that survives an uncertain order, worker freeze, restart and owned reduction.

Creating another adapter or guard does not fence an existing caller. Completion
needs an explicit writer/authority map and real integration evidence.

### 3. The execution trust boundary remains incomplete

Stored key fingerprints and venue/product origin are useful forward bindings;
they are not permanent account UID proof. Enrollment detects ordinary missing or
replaced storage, not every coordinated rollback or malicious rewrite. Selected
HTTP/model children can be terminated; the entire credential-bearing trading
path is not yet a qualified independent gateway/supervisor architecture.

Persistent policy, reservations, marked losses, quarantine, lost-owner handling
and explicit rearm need one coherent authority contract. Owned closing must
remain available independently of model validity and new-entry permission.
