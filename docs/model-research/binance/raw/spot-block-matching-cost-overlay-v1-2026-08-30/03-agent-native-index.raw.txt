## API Reference

### Algo Trading REST API (1.0.0)

Programmatic access to Binance’s execution algorithms for creating and managing Spot and Futures algo orders.

- `DELETE /sapi/v1/algo/futures/order` — Cancel Futures Algo Order (TRADE)
- `GET /sapi/v1/algo/futures/openOrders` — Query Current Futures Algo Open Orders (USER_DATA)
- `GET /sapi/v1/algo/futures/historicalOrders` — Query Historical Futures Algo Orders (USER_DATA)
- `GET /sapi/v1/algo/futures/subOrders` — Query Futures Sub Orders (USER_DATA)
- `POST /sapi/v1/algo/futures/newOrderTwap` — Time-Weighted Futures Average Price (Twap) New Order (TRADE)
- `POST /sapi/v1/algo/futures/newOrderVp` — Volume Participation (VP) New Order (TRADE)
- `DELETE /sapi/v1/algo/spot/order` — Cancel Spot Algo Order (TRADE)
- `GET /sapi/v1/algo/spot/openOrders` — Query Current Spot Algo Open Orders (USER_DATA)
- `GET /sapi/v1/algo/spot/historicalOrders` — Query Historical Spot Algo Orders (USER_DATA)
- `GET /sapi/v1/algo/spot/subOrders` — Query Spot Sub Orders (USER_DATA)
- `POST /sapi/v1/algo/spot/newOrderTwap` — Time-Weighted Spot Average Price(Twap) New Order (TRADE)

### Alpha Trading REST API (1.0.0)

APIs for Binance Alpha Trading.

- `GET /bapi/defi/v1/public/alpha-trade/agg-trades` — Aggregated Trades
- `GET /bapi/defi/v1/public/alpha-trade/fullDepth` — Full Depth
- `GET /bapi/defi/v1/public/alpha-trade/get-exchange-info` — Get Exchange Info
- `GET /bapi/defi/v1/public/alpha-trade/klines` — Klines
- `GET /bapi/defi/v1/public/alpha-trade/ticker` — Ticker
- `GET /bapi/defi/v1/public/wallet-direct/buw/wallet/cex/alpha/all/token/list` — Token List

### Alpha WebSocket Market Streams (1.0.0)

Access Alpha market streams over WebSocket.

- `POST /{symbol}@aggTrade` — Aggregate Trade Stream
- `POST /!bookTicker` — All Book Ticker Stream
- `POST /!miniTicker@arr` — All Mini Ticker Stream
- `POST /!ticker@arr` — All Ticker Stream
- `POST /came@allTokens@ticker24` — All Tokens 24h Ticker Stream
- `POST /{symbol}@bookTicker` — Book Ticker Stream
- `POST /{symbol}@depth{levels}@{interval}` — Partial Depth Stream
- `POST /{symbol}@fulldepth@{interval}` — Full Depth Stream
- `POST /{symbol}@kline_{interval}` — Kline Stream
- `POST /came@{contractAddress}@{chainId}@kline_{interval}` — Contract Kline Stream
- `POST /{symbol}@miniTicker` — Mini Ticker Stream
- `POST /{symbol}@ticker` — Ticker Stream
- `POST /{symbol}@trade` — Trade Stream

### Stocks Trading REST API (1.0.0)

REST APIs for Binance Stocks Trading. All endpoints under `/sapi/v1/equity/*`.

- `GET /sapi/v1/equity/market/exchangeInfo` — Exchange Info (MARKET_DATA)
- `GET /sapi/v1/equity/market/tokenized-assets` — Tokenized Assets (MARKET_DATA)
- `GET /sapi/v1/equity/market/quote` — Latest Quote (MARKET_DATA)
- `POST /sapi/v1/equity/order/place` — Place Equity Order (TRADE)
- `POST /sapi/v1/equity/order/cancel` — Cancel Equity Order (TRADE)
- `POST /sapi/v1/equity/order/cancel-all` — Cancel All Equity Orders (TRADE)
- `GET /sapi/v1/equity/order/open-orders` — Current Open Orders (USER_DATA)
- `GET /sapi/v1/equity/order/history` — Equity Order History (USER_DATA)
- `GET /sapi/v1/equity/order/detail` — Equity Order Detail (USER_DATA)
- `GET /sapi/v1/equity/trade/history` — Equity Trade History (USER_DATA)
- `POST /sapi/v1/equity/tokenized/mint` — Tokenized Mint (TRADE)
- `POST /sapi/v1/equity/tokenized/redeem` — Tokenized Redeem (TRADE)
- `GET /sapi/v1/equity/tokenized/convert-status` — Tokenized Convert Status (USER_DATA)
- `GET /sapi/v1/equity/tokenized/history` — Tokenized Convert History (USER_DATA)
- `POST /sapi/v1/equity/account/disclaimer` — Sign US Equity Disclaimer (TRADE)
- `POST /sapi/v1/equity/listenKey` — Create / Renew Listen Key (USER_STREAM)
