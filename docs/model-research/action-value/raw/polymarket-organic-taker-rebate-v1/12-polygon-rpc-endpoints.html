    Building on Polygon Chain

    Once you’re connected to an RPC endpoint, the next step depends on what you’re building:
    • Polygon Chain overview: architecture, finality, and how the network reaches consensus.
    • Open Money Stack Payments API: for building payment products: fiat on-ramps, off-ramps, stablecoin orchestration, custodial wallets.
    • Non-custodial wallets: non-custodial wallet SDK for consumer apps on Polygon.
    • Cross-chain payments: route customer funds from any token on any chain to a destination on Polygon in a single user action.
    • Estimate gas fees: query the Polygon Gas Station for accurate priority fee recommendations.
